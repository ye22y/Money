## 🎯 개요 및 목표
- **수입/지출 관리**: 월별 급여 수입 대비 고정비/변동비 비중 추적
- **자산 운용 목표**: 당월 잔액(여유 자금) 확보 및 저축률 유지

---

## 📑 카테고리별 지출 항목 (Index Table)

| ID | 구분 | 항목명 | 비고 / 세부내역 |
| :---: | :---: | :--- | :--- |
| **INC-01** | 수입 | 급여 전체액 | 월 실수령액 / 총 수입 예산 |
| **EXP-F01** | 고정 지출 | 대출금 | 주택/신용 대출 원리금 |
| **EXP-F02** | 고정 지출 | 관리비 및 도시가스료 | 아파트 관리비, 가스 요금 |
| **EXP-F03** | 고정 지출 | 보험료 | 보장성/실손 보험료 |
| **EXP-F04** | 고정 지출 | 우기 연금 | 개인연금/저축성 연금 |
| **EXP-V01** | 변동 지출 | 카드 할부 | 카드 할부 대금 |
| **EXP-V02** | 변동 지출 | 용돈 | 개인 생활 용돈 |
| **EXP-V03** | 변동 지출 | 식비 및 생활료 | 장보기, 외식비, 생필품 |
| **EXP-V04** | 변동 지출 | 통신/교통/차량유지비 | 핸드폰비, 버스비, 기름값 |
| **SAV-01** | 저축/투자 | 저금 | 비상금 및 자유 저축 |
